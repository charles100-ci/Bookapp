BOOK++ — VERSION 1

1. Ouvre index.html dans un navigateur.
2. Le site contient des documents de démonstration.
3. Pour ajouter tes vrais PDF :
   - crée le dossier pdf/
   - place tes fichiers PDF dedans
   - ouvre script.js
   - ajoute un document dans le tableau "documents".

Exemple :
{ title: "Mon cours", subject: "Mathématiques", level: "Terminale D", file: "pdf/mon-cours.pdf", icon: "📐" }

IMPORTANT :
Les fichiers PDF de démonstration sont de simples fichiers texte avec extension .pdf.
Remplace-les par de vrais PDF avant de mettre le site en ligne.
